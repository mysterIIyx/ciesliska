Wczesny prototyp platformy produktowej — projekt archiwalny z 2018–2019 roku.

Projekt rozpoczęty jako aplikacja Django z myślą o katalogu produktów i systemie kont użytkowników. Prace zatrzymały się na etapie konfiguracji — modele, widoki i panel admina pozostały puste. Zachowany bez zmian jako punkt odniesienia w portfolio.

Stack: Django 2.2 · Bootstrap 4.3.1 · PostgreSQL · Python 3
